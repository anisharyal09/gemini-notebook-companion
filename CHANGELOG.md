# Changelog

## 1.1.1 — 2026-09-22

Focused Chat only header cleanup.

- Removed the Google Apps launcher from compact mode.
- Removed the account avatar/menu from compact mode.
- Kept Studio and Sources navigation available.

## 1.1.0 — 2026-09-22

UI refresh and workflow improvements for **Gemini Notebook Companion**.

- Refined popup, sidebar, floating window, and Chat only layouts.
- Improved light/dark theme behavior and compact notebook controls.
- Added a draggable page launcher and clearer mode actions.
- Updated extension popup footer with links to support and source.
- Improved Firefox sidebar startup and popup sizing.

## 1.0.0 — 2026-09-21/22

First public release of **Gemini Notebook Companion**.

- Native Firefox sidebar and opt-in Chrome sidebar embedding.
- Reusable, resizable floating window and draggable page launcher.
- Saved notebook links with Google account selection preserved.
- Account-switch navigation returned to the existing companion window when identifiable.
- Compact chat layout, consistent view controls, and light/dark/system themes.
- Mac and Windows/Linux keyboard shortcuts, with assigned keys shown in the popup.
- Local settings, generated icon assets, and MIT license.

  > Note: Earlier 1.1–1.3 labels were local development iterations, not published releases.
